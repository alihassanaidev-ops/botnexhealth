Deploy branch:
ali/phase-3

Environment secrets/vars to upload:

RETELL_API_SECRET=<staging Retell API secret>
Purpose: Lets ScaleNexus place outbound Retell calls and poll Retell call outcomes.

GOTRACKER_BASE_URL=https://synchronizer.scalenexus.ai
Purpose: Base URL for the GoTracker Synchronizer API.

GOTRACKER_WEBHOOK_CALLBACK_BASE_URL=https://api.staging.scalenexus.ai
Purpose: Base URL used by Celery to create GoTracker webhook callback URLs.

GOTRACKER_WEBHOOK_SECRET=<new staging GoTracker webhook HMAC secret>
Purpose: Shared secret used when GoTracker Synchronizer signs webhook events to ScaleNexus.

REDIS_URL=<staging Redis URL>
Purpose: API cache/rate-limit/session backend and shared Redis connection.

CELERY_BROKER_URL=<staging Celery broker URL>
Purpose: Celery worker/beat queue backend for workflow automation jobs.

Per-location app config, not global env:

GoTracker API key=<GoTracker app API key with read,book,webhooks scopes>
Purpose: Store on the staging clinic/location in the current GoTracker key field. This should be the app API key, not the on-prem agent installer product key.
